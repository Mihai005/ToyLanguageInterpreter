# 🖥️ ToyLanguageInterpreter

## 📜 Description
ToyLanguageInterpreter is a **custom programming language interpreter** implemented in **Java**, following the **Model-View-Controller (MVC) pattern**. The interpreter is designed to evaluate expressions, execute statements, and maintain program state, with a **JavaFX-based GUI** for an interactive user experience.

## 🚀 Features

### 🏗️ Model (Core Logic)
- **Abstract Data Types (ADTs)** for structured data management.
- **Expressions**: Numeric, Boolean, Variable, Arithmetic, Logical, Relational.
- **Statements**: Assignments, Conditional, Loops, Forking, File Operations, Declarations, Print, Synchronization Operations.
- **State Management**: Symbol Table, Execution Stack, Heap Table, File Table, Output Table, Barrier Table.
- **Type System**: Integer, Boolean, Reference types, String.
- **Custom Exceptions**: Ensures robust error handling.

### 🎨 View (GUI - JavaFX)
- Interactive interface for defining and executing programs.
- Displays **execution stack, symbol table, and heap memory**.
- Allows users to step through program execution.

### 🕹️ Controller
- Handles communication between the **Model** and the **View**.
- Manages program execution and user interactions.

## 🖥️ Technologies Used
- **Java** for core implementation.
- **JavaFX** for GUI.
- **MVC Architecture** for code organization.
